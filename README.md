# Social Media Management MVP

This workspace contains:

- `frontend`: Vue 3 dashboard UI
- `backend`: Express API

## Run backend

1. Open terminal in `backend`
2. Copy `.env.example` to `.env`
3. Run:

```bash
npm install
npm run dev
```

Backend runs on `http://localhost:4000`.

## Run frontend

1. Open terminal in `frontend`
2. Run:

```bash
npm install
npm run dev
```

Frontend runs on `http://localhost:5173`.

## MVP modules included

- Dashboard KPIs
- Accounts management
- Ideas with scoring formula
- Posts scheduling
- Campaign tracking
- Basic metrics logging
